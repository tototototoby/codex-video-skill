# 浏览器捕获导入

`browser-import` 读取由当前获授权的浏览器工具导出的 JSON 和截图，不负责打开网页、控制播放器、访问页面或采集浏览器配置。只导入当前任务获授权的截图；不要导入浏览器 Cookie、请求头、个人资料目录、令牌或其他会话数据。

## JSON 格式

```json
{
  "duration": 360.0,
  "source_url": "https://example.com/video",
  "frames": [
    {
      "path": "frames/frame-0030.png",
      "requested_time": 30.0,
      "actual_time": 30.04
    }
  ],
  "transcript": [
    {
      "start": 28.5,
      "end": 31.0,
      "text": "播放器当前显示的字幕文本",
      "source": "browser_subtitle"
    }
  ]
}
```

- `duration`、帧时间和字幕时间均以秒表示。`source_url` 可省略；如提供，归档时仅保留 `https://example.com` 这样的来源站点，不保留路径、查询参数或片段。
- `path` 相对于 JSON 文件所在目录。每个截图都应是获授权的浏览器工具实际导出的图像。导入后帧 ID 为 `b.f000000`、`b.f000001` 等。
- `requested_time` 是捕获目标时间；`actual_time` 是外部捕获工具报告的播放器媒体时间。导入程序不会独立核验该时间。使用播放器媒体时间或捕获工具提供的等价读数，不要以请求时间、等待时长或墙上时钟代填。
- `transcript` 是浏览器中实际显示的字幕记录。`start` 与 `end` 是媒体时间，`source` 固定为 `browser_subtitle`。如果只能看到字幕而无法读取准确时间，不要编造时间戳。

导入命令：

```text
python scripts/video.py browser-import CAPTURE_JSON --out RUN --segment-seconds 60
```

此路径用于导入截图与浏览器字幕证据，不代表抓取了连续视频或音频，也不执行 ASR。报告应将这些截图列为离散样本，并将浏览器字幕与本地语音识别分开统计。浏览器导入生成的截图 ID 以 `b.f` 开头；同一分段的字幕 ID 可直接在结论中引用。

## 采集与人工验收

通过当前环境允许的工具打开用户授权的页面。若播放器允许工具下载用户有权获取的视频文件，可把导出的本地文件交给 `prepare`；不要绕过访问控制、抓取 Cookie 或请求头。

只有截图路径可用时，通过可见的播放器控件定位目标位置，读取媒体时间并采集截图；把请求位置和实际位置分别填写。页面不可读取时间或截图失败时，记录缺口，不能用墙钟或预期时间代替实际值。采集期间保持原有浏览器会话和其他标签页。

人工验收时选两个相距较远的位置，比对播放器实际时间、截图内容、导入后的 `actual_time` 与 `drift`；再留一个无截图的分段，确认报告记为 `missing`。这一步需要该页面的合法访问权和当前环境可用的截图导出工具；本仓库不会自建浏览器驱动或凭据通道。
